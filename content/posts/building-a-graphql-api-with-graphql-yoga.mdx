## Problem

Building APIs efficiently is crucial for modern applications. REST APIs often require multiple endpoints for different queries, leading to over-fetching or under-fetching of data. GraphQL addresses these problems by allowing clients to request only the data they need. However, setting up a GraphQL server can be complex and time-consuming if you are not familiar with the right tools.

## Solution with Code

GraphQL Yoga simplifies the process of setting up a GraphQL server. It is built on top of `apollo-server` and `graphql-js`, providing a flexible and easy-to-use API. Here's how you can create a basic GraphQL API using GraphQL Yoga.

First, ensure you have Node.js installed, then initialize a new Node.js project:

```bash
mkdir graphql-yoga-api
cd graphql-yoga-api
npm init -y
```

Install GraphQL Yoga and its dependencies:

```bash
npm install @graphql-yoga/node graphql
```

Create a file named `server.js`. This file will set up your GraphQL server:

```javascript
const { createServer } = require('@graphql-yoga/node');

// Define your types and resolvers
const typeDefs = `
  type Query {
    hello: String
  }
`;

const resolvers = {
  Query: {
    hello: () => 'Hello, world!',
  },
};

// Create a GraphQL Yoga server
const server = createServer({
  schema: {
    typeDefs,
    resolvers,
  },
});

// Start the server
server.start(() => {
  console.log('Server is running at http://localhost:4000');
});
```

Run your server by executing:

```bash
node server.js
```

Visit `http://localhost:4000` in your browser. You should see the GraphQL Playground where you can test queries. Try running:

```graphql
{
  hello
}
```

## Key Concepts

- **GraphQL Schema**: Defines the types and structure of data that can be queried or mutated. In this example, we defined a simple schema with a `Query` type that includes a `hello` field.

- **Resolvers**: Functions that provide the response for a query or mutation. Our `hello` resolver returns a static string.

- **GraphQL Yoga**: A flexible and extensible GraphQL server that simplifies the setup process. It provides a built-in Playground for testing queries.

By using GraphQL Yoga, you can quickly set up a GraphQL server that allows clients to fetch only the data they need, reducing over-fetching and under-fetching issues common in REST APIs. This setup provides a starting point to expand and integrate more complex queries and mutations.
